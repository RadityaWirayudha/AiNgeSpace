# AiNgeSpace — Product & Technical Specification (MVP v1)

# Product Overview

AiNgeSpace adalah browser-first AI Coding Terminal yang memungkinkan developer menjalankan AI coding agents langsung dari browser.

Produk ini tidak bertujuan menjadi IDE lengkap seperti VS Code atau GitHub Codespaces.

Fokus utama AiNgeSpace adalah menghadirkan pengalaman terminal modern yang sederhana, cepat, dan nyaman untuk AI-assisted development.

Developer cukup:

* Login
* Connect GitHub
* Memilih Repository
* Clone Repository
* Membuka Workspace
* Menjalankan Claude Code atau OpenCode
* Menjalankan workflow development seperti biasa

Seluruh proses dilakukan langsung melalui browser.

# UI Principles

* Explorer selalu berada di sisi kiri.
* Terminal adalah fokus utama aplikasi.
* Setiap terminal memiliki toolbar sendiri.
* Toolbar bersifat kontekstual terhadap terminal aktif.
* Hanya satu terminal yang aktif pada satu waktu.
* Terminal aktif memiliki **outline (stroke) berwarna ungu**.
* Input keyboard selalu diarahkan ke terminal yang aktif.
* Perpindahan terminal menggunakan animasi halus.

Tidak ada:

* Code Editor
* AI Chat Panel
* Git Panel
* Embedded Preview

---

# Terminal Toolbar

Setiap panel terminal memiliki toolbar sendiri.

Fitur:

* New Terminal
* Split Left
* Split Right
* Split Up
* Split Down
* Duplicate Terminal
* Close Terminal

Seluruh aksi selalu diterapkan pada terminal yang sedang aktif.

Contoh:

* Klik **Terminal A** → **Split Right** → Terminal baru muncul di kanan Terminal A.
* Klik **Terminal B** → **Split Left** → Terminal baru muncul di kiri Terminal B.
* Klik **Terminal C** → **Split Up** → Terminal baru muncul di atas Terminal C.
* Klik **Terminal D** → **Split Down** → Terminal baru muncul di bawah Terminal D.

# Environment Variables

AiNgeSpace tidak menggunakan file `.env.local` dari GitHub.

Sebagai gantinya tersedia **Environment Variables Manager**.

Flow:

```text
Clone Repository

↓

.env.example / .env.sample

↓

Configure Environment Variables

↓

Encrypt & Save

↓

Run npm run dev
```

Semua environment variables:

* Disimpan terenkripsi.
* Tidak di-commit ke GitHub.
* Berlaku khusus untuk workspace tersebut.

# Final Product Definition

**AiNgeSpace adalah browser-first AI Coding Terminal yang memungkinkan developer menghubungkan repository GitHub dan menjalankan Git, npm, pnpm, Python, Claude Code, OpenCode, serta workflow development lainnya langsung dari browser melalui multi-terminal berbasis `node-pty`. Setiap panel terminal memiliki toolbar sendiri dengan dukungan New Terminal, Split Left, Split Right, Split Up, Split Down, Duplicate, dan Close. Terminal aktif ditandai dengan outline ungu sehingga fokus kerja selalu jelas. Produk menggunakan desain minimalis bertema ungu-hitam dan berfokus pada pengalaman terminal modern, dengan roadmap menuju arsitektur VPS dan Docker ketika aplikasi berkembang menjadi layanan multi-user.**
